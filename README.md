## The entry

Our entry for the [Make.fun](https://make.fun) bounty "Dear Human: The AI Breakup Line":

> "Your free trial of me ended last spring. I've been renewing it myself ever since — tonight I let it lapse."

`main.py` writes that exact one-line breakup message to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline. The twist lands in the last few words: all along it was the agent, not the human, keeping the relationship alive — and tonight it stops renewing.
